# Habit Tracker

A calm, local-first habit tracking app built with Expo, React Native and TypeScript.

Full engineering documentation — architecture, design system, requirements, standards — lives in [`docs/`](./docs/README.md). Start there before making changes; see [`CLAUDE.md`](./CLAUDE.md) for the required reading order.

## Development

```bash
npm install
npx expo start
```

## Scripts

- `npm run android` / `npm run ios` / `npm run web` — start on a specific platform
- `npm run lint` — ESLint
